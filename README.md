# 🧸 폴라로이드 데이

갤러리에서 **하트만 누르면**, 매달 마지막 주 수요일에 Claude가 그 사진들을 **포토몬 폴라로이드 장바구니에 담아줘요.**
엄마가 할 일은 하트 누르기와 결제 버튼 누르기, 두 가지뿐이에요.

- 하트 사진이 11장(22장, 33장…)이면 묻지 않고 바로 담아요. 장수가 안 맞으면 알려드려요.
- 한 번 인화한 사진은 기록해 두고 다시 담지 않아요.
- **결제는 언제나 엄마가 직접 해요.** Claude는 결제와 비밀번호 입력을 하지 않아요.

## 준비물

| 준비물 | 설명 |
| --- | --- |
| 컴퓨터 | 매달 마지막 주 수요일 오전에 켜져 있어야 해요 |
| Claude 데스크톱 앱 + 유료 요금제(Pro 이상) | 예약 작업이 되는 요금제가 필요해요 |
| Chrome + Claude 확장 프로그램 | Chrome에서 `claude.ai/chrome` 에 들어가 설치해요 |
| Git for Windows (Windows만) | 플러그인 설치에 필요해요. [git-scm.com](https://git-scm.com/download/win)에서 받아 기본값으로 설치한 뒤 Claude 앱을 다시 켜요 |
| 아이폰: iCloud 사진 / 갤럭시: 구글 포토 | 갤럭시는 **구글 포토 앱에서 ☆**를 눌러야 해요(기본 갤러리 앱 하트는 안 넘어가요) |
| 포토몬 계정 | photomon.com (카카오·네이버 로그인 가능) |

## 설치하기 (Claude 데스크톱 앱)

1. Claude 데스크톱 앱 **Code** 탭에서 **새로 생성**으로 새 세션을 열어요.
2. 입력창 왼쪽 **+** → **플러그인 추가**를 눌러요.
3. 열린 창 오른쪽 위 **+**(마켓플레이스 추가)를 누르고 아래를 입력한 뒤 **동기화**를 눌러요.
   ```
   wjdduf0721/polaroid-day
   ```
4. **Code** 탭에 나온 **Polaroid day** 카드의 **+**를 눌러 설치해요.

터미널을 쓰신다면 이 한 줄이면 돼요.
```
/plugin install polaroid-day --marketplace wjdduf0721/polaroid-day
```

## 시작하기

입력창에 이렇게 써요.
```
/polaroid-day:setup
```
Claude가 "아이폰이에요, 갤럭시예요?"처럼 몇 가지를 물어보고, 로그인을 같이 확인한 뒤 매달 자동 인화를 예약해요. 처음 한 번만 하면 돼요.

## 쓸 수 있는 명령

| 입력 | 하는 일 |
| --- | --- |
| `/polaroid-day:setup` | 처음 설정 (휴대폰 종류, 기록 폴더, 예약 만들기) |
| `/polaroid-day:print-now` | 날짜와 상관없이 지금 바로 인화 준비 |
| `/polaroid-day:history` | 지금까지 인화한 기록 보기 |

## 꼭 알아두세요

- **컴퓨터, Claude 앱, Chrome이 켜져 있어야 해요.** 꺼져 있으면 다음에 켤 때 실행돼요.
- **iCloud·구글 포토·포토몬 로그인이 풀리면** Claude가 "다시 로그인해 주세요"라고 알려줘요.
- **포토몬 장바구니는 2주 동안 보관돼요.** 그 안에 결제하면 돼요.
- **사이트 화면이 바뀌면 멈출 수 있어요.** 그럴 땐 Claude가 어디서 막혔는지 알려줘요.
- 갤럭시(구글 포토) 방식은 아직 많이 시험되지 않았어요. 막히는 곳이 있으면 알려주세요.
- 무료 iCloud(5GB)나 구글(15GB) 용량이 차지 않게, 결제 후 백업을 확인하고 사진을 정리해 주세요.

## 막혔을 때

- **"Git이 필요합니다"가 떠요** → Git for Windows를 설치하고 Claude 앱을 완전히 껐다가(오른쪽 아래 트레이 아이콘까지) 다시 켜요.
- **"마켓플레이스 추가에 실패했습니다"가 떠요** → 주소를 `wjdduf0721/polaroid-day` 그대로(앞뒤 띄어쓰기 없이) 넣었는지, 인터넷이 연결됐는지 확인하고 다시 **동기화**를 눌러요.
- **명령이 안 보여요** → 새 세션 입력창 왼쪽 **+ → 플러그인 → Polaroid day**에서 setup을 눌러도 돼요.
