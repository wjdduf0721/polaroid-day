설치하기 · 약 10분

프롬프트 붙여넣기 없이, 플러그인으로

  1. 새 세션 열기

    Claude 데스크톱 앱 Code 탭에서 왼쪽 위 새로 생성을 눌러요.

  2. + → 플러그인 추가

    입력창 왼쪽 + 버튼을 누르고 맨 아래 플러그인 추가를 눌러요.

  3. 마켓플레이스 추가

    열린 창 오른쪽 위 +를 누르고 아래 주소를 넣은 뒤 동기화를 눌러요.

    wjdduf0721/polaroid-day

  4. Polaroid day 설치

    Code 탭에 나온 Polaroid day 카드의 +를 눌러요.

  5. 설정 시작

    창을 닫고 입력창에 /polaroid-day:setup 입력. Claude가 "아이폰이에요, 갤럭시예요?"처럼 물어보면서 로그인 확인과 매달 예약까지 같이 해줘요.

입력하는 일
/polaroid-day:setup처음 설정 (한 번만)
/polaroid-day:print-now날짜와 상관없이 지금 바로 인화 준비
/polaroid-day:history지금까지 인화한 기록 보기

이것만 기억하면 매달 편해요

  • 하트는 11장 단위로11장, 22장…이면 묻지 않고 바로 담아요. 장수가 안 맞으면 추천 사진과 함께 알려줘요.
  • 그날 아침엔 켜 두기컴퓨터·Claude 앱·Chrome이 켜져 있어야 해요. 꺼져 있으면 다음에 켤 때 실행돼요.
  • 로그인이 풀리면Claude가 "다시 로그인해 주세요"라고 알려줘요. 비밀번호는 직접 입력해요.
  • 장바구니는 2주 보관포토몬 장바구니는 2주 동안 남아 있어요. 그 안에 결제하면 돼요.
  • 용량 관리무료 iCloud(5GB)·구글(15GB)이 차지 않게, 결제 후 백업을 확인하고 사진을 정리해요.
  • 휴대폰 알림Claude 앱 설정에서 Remote Control을 켜면 휴대폰으로도 알림이 와요.
자주 묻는 질문

막혔을 때

"Git이 필요합니다"가 떠요

윈도우에 Git이 없어서예요. Git for Windows를 기본값으로 설치하고, Claude 앱을 완전히 껐다가(오른쪽 아래 트레이 아이콘까지) 다시 켜요.

"마켓플레이스 추가에 실패했습니다"가 떠요

주소를 wjdduf0721/polaroid-day 그대로(앞뒤 띄어쓰기 없이) 넣었는지, 인터넷이 연결됐는지 확인하고 다시 동기화를 눌러요. Git을 방금 설치했다면 Claude 앱을 다시 켜야 해요.

명령이 안 보여요

새 세션을 열고 입력창 왼쪽 + → 플러그인 → Polaroid day에서 setup을 눌러도 돼요.

사진이 옆으로 누워서 나오지 않나요?

휴대폰 사진은 회전 정보만 따로 들고 있어서 인화 사이트에서 누울 때가 있어요. 그래서 Claude가 올리기 전에 사진을 실제로 세워서 따로 저장해 둬요.

"주문하기"가 막혔다고 나와요

Claude의 안전장치가 결제로 이어질 수 있는 버튼을 막은 거예요. 열려 있는 포토몬 편집기에서 주문하기를 직접 누르면 장바구니에 담겨요.

Claude 무료 버전으로도 되나요?

아쉽지만 안 돼요. 예약 작업과 Code 탭이 되는 유료 요금제(Pro 이상)와 컴퓨터가 필요해요.
