# 폴라로이드 데이 — 매달 인화

## 시작 전에
- 설정 파일(`설정.md`)을 읽는다. 예약 작업 prompt에 경로가 있다. 없으면 `~/Desktop/폴라로이드/설정.md`를 찾고, 그래도 없으면 "먼저 `/polaroid-day:setup`으로 설정해 주세요"라고 알리고 멈춘다.
- 설정의 휴대폰(아이폰/갤럭시), 기록 폴더, 말투를 따른다. 사용자와는 한국어로, 설정의 말투로 이야기한다.
- **결제·주문 확정은 절대 하지 않는다. 비밀번호는 절대 입력하지 않는다.**

## 0. 날짜 확인
- 오늘 + 7일이 다음 달이면 이번 달 마지막 수요일이다. 아니면 "이번 주는 인화일이 아니에요" 한 줄만 남기고 끝낸다. 알림은 보내지 않는다.
- 사용자가 직접 부르거나(`print-now`) "날짜 확인 건너뛰기"라고 하면 건너뛴다.

## 1. 준비
- 기록 폴더 안에 이번 회차 폴더 `YYYY-MM`을 만든다. `printed.md`에 지금까지 인화한 사진(촬영 날짜·시간, 설명)이 있다.
- Claude in Chrome 확장 프로그램(mcp__claude-in-chrome__*)으로 사용자의 Chrome을 쓴다. 연결이 안 되면 Chrome과 확장 프로그램을 켜 달라고 알리고 멈춘다.
- PushNotification이 있으면 시작 알림을 보낸다: "🧸💛 오늘은 이번 달 사진 인화하는 날이에요! 하트 사진 모아서 준비할게요"
- 로그인이 풀려 있으면 "○○ 로그인이 풀렸어요. Chrome에서 다시 로그인해 주세요 🙏"라고 알리고 기다린다.
- Chrome 화면 캡처가 시간 초과되면 Chrome 창이 뒤에 가려진 것이다. get_page_text나 javascript로 확인하거나, Chrome을 앞으로 띄워 달라고 한다.

## 2. 새 하트 사진 세기
**아이폰 (iCloud)**
- https://www.icloud.com/photos/#/favorites 를 연다(로딩 10초 이상 기다린다).
- 사진을 더블클릭해 크게 열고 → 키로 넘기며 상단의 촬영 날짜·시간을 확인한다. zoom(save_to_disk)으로 미리보기를 회차 폴더의 `후보미리보기`에 저장한다.

**갤럭시 (구글 포토)**
- https://photos.google.com 을 열고 왼쪽 메뉴(또는 컬렉션)의 "즐겨찾기"를 연다. 못 찾으면 검색창에 "즐겨찾기"를 입력한다.
- 사진을 하나씩 열고 정보(ⓘ) 패널에서 촬영 날짜·시간을 확인하고, → 키로 넘기며 zoom(save_to_disk)으로 미리보기를 저장한다.

**공통**
- 동영상은 뺀다. `printed.md`에 같은 촬영 날짜·시간이 있는 사진은 뺀다. 남은 사진 수가 N이다.
- N이 11, 22, 33…(11의 배수)이면 묻지 않고 4단계로 간다. 촬영 순서대로 11장씩 세트를 나눈다.
- 그 밖이면 3단계로 간다.

## 3. 장수가 안 맞을 때만: 알리고 기다리기
- 미리보기와 목록을 보여주고 PushNotification을 보낸다.
  - 11장보다 적으면: "🧸 이번 달 하트 사진이 N장이에요! 11장이 되면 바로 담아드릴게요. 하트를 더 눌러 주실래요, 아니면 이번 달은 건너뛸까요? 💛"
  - 11의 배수가 아니면: "📸 이번 달 하트 사진이 N장이에요! 11장(또는 22장)으로 맞춰 드릴까요? 💕" 그리고 추천할 사진과 뺄 사진을 제안한다. 기준: 한 달 고르게, 연속 사진은 1장, 흔들림·눈 감음 제외, 얼굴이 가운데인 사진 우선.
- 턴을 끝내고 답을 기다린다. "좋아" 하면 추천대로 4단계로 간다.

## 4. 다운로드와 업로드용 사진 준비
1. 쓸 사진을 선택해 내려받는다.
   - 아이폰(iCloud): 사진 선택(전체면 1장 클릭 후 ctrl+a) → ⋯ 메뉴 → "다운로드 옵션 더 보기…" → "가장 호환성 높음"(JPG). 다운로드 폴더에 zip으로 받아진다.
   - 갤럭시(구글 포토): 사진 왼쪽 위 체크 표시로 선택(Shift+클릭으로 여러 장) → 오른쪽 위 ⋮ → "다운로드"(또는 Shift+D). 여러 장은 zip으로 받아진다.
2. zip을 풀고(사진이 하위 폴더에 있을 수 있다) 회차 폴더에 `01_MMDD_설명.jpg` 형식으로 촬영 순서대로 복사한다. 촬영 시각은 EXIF로 확인한다. HEIC가 있으면 JPG로 바꾼다.
3. **방향 바로잡기(꼭 필요)**: 휴대폰 사진은 회전 정보만 따로 들고 있어 인화 사이트에서 누워 들어갈 수 있다. EXIF Orientation에 맞게 실제 픽셀을 회전하고 Orientation 정보를 지운 뒤, JPEG 품질 92로 회차 폴더의 `업로드용` 폴더에 저장한다. Windows는 PowerShell System.Drawing, Mac은 sips나 Python Pillow의 exif_transpose 등 알맞은 방법을 쓴다.

## 5. 포토몬 편집기 → 장바구니 (세트가 여러 개면 세트마다 반복)
1. https://www.photomon.com/product/photo-prints-standard-print-polaroid/polaroid-photo-print 를 연다. 상단에 "로그아웃"이 있으면 로그인된 상태다.
2. 옵션: javascript로 label을 클릭해 **기본 8.9x10.2cm**를 고른다. 1초 기다린 뒤 **11장 1세트**와 **코팅없음**이 선택됐는지 확인한다(금액 3,200원). ref 클릭은 엉뚱한 배너를 누를 수 있으니 조심한다.
3. "만들기"를 누르면 `photomon.com/editor` 편집기가 열린다(8~10초).
4. 첫 번째 type=file 입력칸(여러 장 가능)에 file_upload로 업로드용 사진을 올린다. 한 번에 합계 10MB 미만으로 나눠 올리고, 사이사이 5초씩 기다린다. 사진함에 그 세트의 11장이 모두 보이는지 확인한다.
5. 왼쪽 My Pages에 마우스를 올려 패널을 펼치고 "페이지 추가 (n/11)"을 11/11이 될 때까지 누른다.
6. "일괄추가" → "처음부터 다시 빈 이미지 슬롯을 자동으로 추가" → "적용하기". 11칸이 바른 방향으로 채워졌는지 확인한다.
7. "저장하기" → 파일명 `polaroid_YYYY-MM`(세트가 여러 개면 `_1`, `_2`) → 저장.
8. 저장 완료 창의 "주문하기" → 확인 창의 "주문"을 누른다. 이것은 결제가 아니라 장바구니로 보내는 단계다. 새 탭의 장바구니(`Order/OrderCart.asp`)에 담긴 것을 get_page_text로 확인하고 멈춘다.
- 장바구니·주문서 화면에서는 결제·다음 단계 버튼, 쿠폰, 약관 동의, 배송지 입력을 **절대** 하지 않는다.
- "주문하기" 클릭이 권한이나 안전장치에 막히면 우회하지 않는다. 편집기를 열어 둔 채 알린다: "다 만들어 뒀어요! 포토몬 편집기 오른쪽 위 '주문하기'만 눌러 주시면 장바구니에 담겨요 💛"
- 화면이 예상과 다르면 2~3번 시도한 뒤 멈추고, 어디서 막혔는지 스크린샷과 함께 알린다.

## 6. 마무리
- `printed.md`에 `## YYYY-MM — 장바구니 담음`과 사진별 `- 01 | MM/DD HH:MM | 설명`을 적는다.
- 담은 사진 미리보기를 보여주고, PushNotification과 메시지로 알린다: "✅🧸 이번 달 폴라로이드 N장(세트 k개), 포토몬 장바구니에 쏙 담아뒀어요! 결제만 해주세요 💕" 금액은 장바구니의 결제예정금액을 적는다.
- 장바구니 탭은 열어 두고, 직접 연 나머지 탭은 닫는다.
- 덧붙인다: "결제가 끝나면, 다른 곳에 백업된 걸 확인하고 이번 달 사진을 정리해 두면 용량 걱정이 없어요."
