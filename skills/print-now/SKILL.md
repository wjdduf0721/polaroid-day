# 폴라로이드 데이 — 지금 바로 인화

1. 기록 폴더의 `설정.md`를 찾는다(기본: 바탕화면의 `폴라로이드` 폴더). 없으면 "먼저 `/polaroid-day:setup`으로 설정해 주세요"라고 알리고 멈춘다.
2. "지금 바로 이번 달 인화를 준비할게요 🧸"라고 알린다.
3. `monthly-print` 스킬을 그대로 따르되, **0단계(날짜 확인)는 건너뛴다.**
4. 결제는 절대 하지 않는다. 장바구니에 담고 멈춘다.
