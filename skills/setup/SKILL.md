# 폴라로이드 데이 — 처음 설정

엄마가 하트 누른 아이 사진을 매달 포토몬 폴라로이드 장바구니에 담아주는 기능을 설정한다.
한국어로, 쉽고 다정하게 이야기한다. 어려운 용어(경로, 크론, 스킬 등)는 쓰지 않는다.

## 1. 환영 인사와 준비물 확인
먼저 짧게 소개한다: "하트만 누르면, 매달 마지막 주 수요일에 폴라로이드를 장바구니에 담아둘게요. 결제는 엄마가 직접 해요."

아래를 하나씩 확인한다. 안 된 것이 있으면 그것부터 같이 한다.
1. Chrome에 Claude 확장 프로그램이 연결돼 있는지: Claude in Chrome 도구(mcp__claude-in-chrome__*)로 연결된 브라우저가 있는지 확인한다. 없으면 "Chrome에서 claude.ai/chrome 에 들어가 확장 프로그램을 설치하고 로그인해 주세요"라고 안내하고 기다린다.
2. 휴대폰 종류를 묻는다(AskUserQuestion이 있으면 버튼으로): **아이폰** / **갤럭시(안드로이드)**.
3. 사진 사이트 로그인:
   - 아이폰: Chrome 새 탭에서 https://www.icloud.com/photos/ 를 열어 로그인돼 있는지 본다. 아이폰 설정 → 내 이름 → iCloud → 사진 → "이 iPhone 동기화"가 켜져 있어야 한다고 알려준다.
   - 갤럭시: https://photos.google.com 을 열어 로그인돼 있는지 본다. "갤럭시 기본 갤러리 앱의 하트는 구글 포토로 넘어가지 않아요. 구글 포토 앱에서 ☆를 눌러주세요"와 "구글 포토 앱 → 프로필 → 백업 켜기"를 꼭 알려준다.
   - 로그인돼 있지 않으면 엄마에게 직접 로그인해 달라고 하고 기다린다. **비밀번호는 절대 대신 입력하지 않는다.**
4. 포토몬 로그인: https://www.photomon.com 을 열어 상단에 "로그아웃"이 보이는지 확인한다. 아니면 직접 로그인(카카오·네이버 가능)해 달라고 하고 기다린다.
5. 직접 연 탭은 확인이 끝나면 닫는다.

## 2. 몇 가지 묻기
- 기록 폴더: 기본값은 바탕화면의 `폴라로이드` 폴더(Windows: `%USERPROFILE%\Desktop\폴라로이드`, Mac: `~/Desktop/폴라로이드`). "여기에 매달 인화한 사진과 기록을 모아둘게요. 괜찮을까요?"
- 알림 말투: 기본값 "다정하고 몽글몽글하게". 바꾸고 싶은지 한 번만 묻는다.

## 3. 설정 파일 만들기
기록 폴더를 만들고 그 안에 `설정.md`를 쓴다:

```
# 폴라로이드 데이 설정
- 휴대폰: 아이폰 | 갤럭시
- 사진 사이트: iCloud | 구글 포토
- 기록 폴더: <절대 경로>
- 말투: <말투>
- 인화 상품: 포토몬 폴라로이드 기본 8.9x10.2cm, 11장 1세트, 코팅없음
- 만든 날: <오늘 날짜>
```

같은 폴더에 `printed.md`가 없으면 `# 인화 기록` 한 줄로 만든다.

## 4. 예약 작업 만들기
예약 작업 도구(mcp__scheduled-tasks__create_scheduled_task, 없으면 ToolSearch로 불러온다)로 만든다.
- taskId: `polaroid-day-monthly`
- title: `【매달 마지막 주 수요일】폴라로이드 데이`
- cronExpression: `0 9 * * 3` (매주 수요일 오전 9시, 작업 안에서 마지막 수요일인지 스스로 확인)
- prompt (기록 폴더 경로를 실제 값으로 채운다):

```
polaroid-day 플러그인의 monthly-print 스킬을 그대로 따라 실행해 줘.
설정 파일: <기록 폴더>/설정.md
```

이미 같은 이름의 작업이 있으면 새로 만들지 말고 그 작업의 prompt만 바꾼다.

## 5. 마무리 안내
짧게 알려준다:
- "매주 수요일 오전 9시에 확인하고, 마지막 주 수요일에만 인화를 준비해요."
- "그 시간에 컴퓨터, Claude 앱, Chrome이 켜져 있어야 해요. 꺼져 있으면 다음에 켤 때 실행돼요."
- "하트 사진이 11장(또는 22장, 33장…)이면 묻지 않고 바로 장바구니에 담아요. 장수가 안 맞으면 알려드릴게요."
- "지금 바로 해보고 싶으면 `/polaroid-day:print-now` 라고 입력하세요."
- "휴대폰으로도 알림을 받으려면 Claude 앱 설정에서 Remote Control을 켜세요."
